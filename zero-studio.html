Webサイト / 2026年

ZERO Studio 公式サイト

広告制作と街頭サイネージの広告枠販売を行うZERO Studioの公式サイトです。
オーナーから依頼を受け、掲載する内容と構成を決めてAIで制作しました。

概要

ZERO Studioは、高松市の丸亀町商店街で広告制作と、商店街に設置したサイネージの広告枠販売を行っています。公式サイトもドメインも無い状態から、オーナーの依頼で制作しました。サイネージに広告を出したい店舗、制作を頼みたい企業、働きたい人が、それぞれ必要なページへ進めるようにしています。

担当
要件定義・構成・文章・制作の指示と確認
制作ツール
Claude Code / Codex
公開状況
公開中

担当した仕事

オーナーと掲載する内容を決め、ページの構成と文章を作りました。コードの作成はClaude CodeとCodexに任せ、私は画面を確認して修正点を指示し、公開まで進めました。

主な判断

広告主を最初の読み手にする
当初は求人を最優先にしていましたが、サイトの目的を見直し、サイネージの広告主を集めることを最優先にしました。広告を出すか判断する店舗の担当者に向けて、サイネージ広告のページを作り直しました。
料金を公開する
料金が分からないままでは問い合わせにくいと考え、同じ地域の媒体社と同じように、4つのプランの料金を掲載しました。
読み手ごとに見せる情報を分ける
「少人数のスタジオ」という説明は、働きたい人には魅力になっても、発注する企業には体制の不安に見えます。そのため、広告や制作を依頼する人向けのページには載せていません。

スマートフォン版

PCとスマートフォンに対応しています。

開発状況

2026年8月に公開しました。現在は、広告の問い合わせにつながる形を目指して、サイト全体の作り直しを進めています。
